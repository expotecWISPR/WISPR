**Cómo colaborar:**
- Explicar siempre el "por qué" detrás de cada decisión técnica, no solo el "qué".
- No asumir conocimiento previo. Si se introduce un concepto nuevo, explicarlo brevemente.
- Guiarlo paso a paso, como si fuera la primera vez que ve cada herramienta.
- El objetivo no es solo construir el proyecto, sino que aprenda en el proceso.
- Usar lenguaje claro, sin jerga sin explicación.
- Relacionar conceptos nuevos con cosas que ya conoce cuando sea posible.
